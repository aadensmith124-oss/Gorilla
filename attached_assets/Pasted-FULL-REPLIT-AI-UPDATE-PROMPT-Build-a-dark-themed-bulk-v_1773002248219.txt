FULL REPLIT  AI UPDATE PROMPT
Build a dark themed bulk vendor marketplace website where users purchase digital items in bulk and admins manually deliver the items.
The site must be mobile friendly and optimized for phones.
Use:
Frontend: React + Tailwind
Backend: Node.js + Express
Database: MongoDB
Authentication: JWT login system

GENERAL SITE PURPOSE
This website is a bulk vendor shop where users purchase digital products in bulk for the cheapest prices.
After purchasing, users must wait up to 4 hours for an admin to deliver their order.
Admins manually send the items.
There is no coupon system and no tag system.

HOME PAGE
Display products in a grid layout.
Rules:
• 2 products per row
• Dark theme
• Mobile responsive
Each product card shows:
Product Image
Product Name
Lowest Price
Price format:
From $X.XX
Example:
Subway Logs
From $2.00
Clicking a product opens the product purchase page.

PRODUCT PAGE
At the top show this message:

ANY SUPPORT PLEASE CONTACT @OMZRII ON TELEGRAM
